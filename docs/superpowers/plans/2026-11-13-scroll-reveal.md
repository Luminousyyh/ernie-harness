# 展示站渐进展开

已批准方案：保留自然滚动，首次进入视口时逐段淡入上移。桌面24px/650ms与0、80、160ms错峰；手机16px/480ms与60ms错峰。单个 IntersectionObserver，rootMargin 底部 -48px，阈值0.08。

使用非嵌套 data-reveal 标记。首屏立即可见；展开不改高度，回滚不重播。没有 JavaScript/观察接口、初始化或回调失败、打印、减少动态效果时内容全部可读。键盘焦点与页内锚点立即暴露目标。

浏览器检查覆盖一次性展开、错峰时序、锚点/焦点、快速滚动和窗口调整、无JS/接口/失败回退、减少动态效果切换、打印及既有交互。完整截图前逐段展开；另保存桌面和手机实际滚动录屏。

完成标准：site:qa、pnpm check、独立复核通过；发布到现有 GitHub Pages，验证线上资源哈希与桌面/手机滚动。

实现说明：等待展开的透明区域不接收指针事件；已可见按钮的鼠标焦点不会取消祖先的位移动画，防止按下/抬起之间按钮位置改变而丢失点击。键盘焦点仍立即显示内容。
