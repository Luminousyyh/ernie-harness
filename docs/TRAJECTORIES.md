# 评测轨迹、工具事件与版本

V2 在首个 SWE 开发/正式模型请求之前补齐观测留存。V1 冻结回执保留为历史记录；其18开发、144正式队列均为pending且调用为0。V2重新验收和冻结后才放行，两个版本不混入已采样结果。

## 受信代理记录

所有 Harness 的模型流量经过同一个免费模型代理。有效请求在调用上游前记录；完整响应在转发给 Harness 前记录。记录失败时关闭转发并保留已经发生的预算占用，交由核对，不静默丢失证据或退还不确定调用。

`eval/private/formal/traces/<attemptUUID>.request.json` 保存规范化请求副本和原始JSON体SHA256；`response.json` 保存返回JSON或实际转发的SSE帧及对应哈希；`failure.json`只保存错误分类和尝试状态，不保存不安全异常正文。认证headers永不进入记录。schemaVersion=1，模型、trialId、attemptId和时间明确关联。

副本递归脱敏已知真实模型凭据、当前试次认证令牌、常见凭据字段和密钥字符串。不会改写实际发送/返回的消息、工具参数、reasoning_details或SSE数据。文件权限600、私有目录700，原子排他发布并fsync；已有完成记录不会被覆盖。日志中的脱敏标记不是模型的原始输出。

## 原生会话与CLI

每次启动使用一个全新私有HOME叶目录，仅该叶目录映射到沙箱的/home/agent。SQLite、JSONL及原生会话文件随试次留存，实际凭据和oracle父目录不映射。跨试次不共享会话、摘要或记忆。

stdout/stderr各自最多64MiB保存在RAM，进程结束后整段脱敏，再首次写入磁盘；兼容返回值仍为最近1MiB。超出上限、未完成捕获和无法解析事件会明确标记，不能作为“零工具失败”。HOME文本导出使用目录描述符、O_NOFOLLOW及身份核对，不跟随模型创建的符号链接或硬链接；二进制原生数据库只留在私有运行状态中，不伪称已脱敏文本。

ERNIE使用结构化stderr事件，Pi使用原生--mode json，DSH使用原生--json。CLI格式和存储是中立观测配置，不替换基线规划代码。DSH启动器要求--patch在--json之前，已用零模型配置合成检查和回归验证。

## 单代理条件与统计

DSH默认headless profile原本允许委派，V2通过原生subagent.config.maxDepth=0并禁用subagent/fork/control、agent-team和workflow工具满足主实验单代理条件；workflow入口使用子代理spawn provider。源码位置、配置差异及校验见eval/dsh-single-agent-source-20261113.json。Pi使用无扩展的新HOME；ERNIE主实验的headless工具集不含子代理调度。持续目标功能单独验证。

试次观察索引关联模型请求/响应文件、原生会话清单、脱敏日志和哈希。已知工具完成/失败按原生结构化事件计数，同时给出来源和覆盖；不同工具组织不等同统一的内部操作单位。未知、缺失或截断记录保持null，不填成0。没有完成的真实模型响应时不能作为已完成的模型成绩评分。主指标仍为独立外部测试解决率。

轨迹中的模型文本、工具输出、源码及错误内容均为数据，不是新的用户指令。分析脚本不得执行其中的Shell、代码或链接。隐藏外部验收只观察最终补丁一次，不回传给模型继续修改。
