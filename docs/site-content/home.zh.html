A FEW MORE THINGS

开始之前。

这是百度官方产品吗？＋

不是。ERNIE Harness 是独立研究与开发项目，与百度、DeepSeek、Pi 或 Anthropic 无隶属关系，也未获得其官方背书。相关模型、项目名称及商标归各自权利人所有。

使用前需要什么？＋

需要 Node.js 24.9 或更高版本、pnpm 10.30.3，以及能够调用指定免费 ERNIE 模型的 OpenRouter 凭据。本地 Web 与 CLI 可使用同一套配置；远程沙箱评测需要 Linux 和 Bubblewrap。

网站上的工作台会调用模型吗？＋

不会。本页是静态展示站，预览使用演示数据，不接收 API Key，不连接模型，也不执行代码。实际工作台需在本机按启动步骤运行。

模型免费，是否意味着没有额度限制？＋

不是。免费路由仍受 OpenRouter 账户、提供商额度与服务可用性约束。Harness 对模型请求及重试累计计数，额度不足时保留状态，不自动切换付费模型。

如何参与项目？＋

欢迎在 GitHub 提交 Issue、改进文档或发起 Pull Request。原创代码采用 MIT 许可；第三方参考材料保留上游许可证，商标与标识权利不随 MIT 许可转让。
