## Native trajectory retention (V2, integration held)

Every launch creates a fresh private HOME below `ROOT/eval/private/adapter-records/<trial>/<harness>-<launch>/home`; only that leaf is mounted writable. Its parent, credential/vault/oracle directories and previous trial homes remain inaccessible. Native session SQLite/JSONL is retained privately after sandbox exit. `capture-started.json` is fsynced before launching the child and records the sanitized native command, stream caps and event schema.

Stdout and stderr are buffered separately in RAM, capped at 64 MiB each, with observed/retained byte counts and explicit truncation flags. Each whole retained capture is sanitized before its first disk log write; there is no raw stdout/stderr disk log. A host crash before exit can lose these RAM buffers; the durable capture-started receipt and broker traces then establish an incomplete observation, never zero events. The compatibility return retains only the sanitized last 1 MiB; it is not the trajectory archive. After exit, `manifest.json` links sanitized log paths/hashes under `sanitized/`, plus the original in-memory capture hash for provenance. Native HOME files remain private and sanitized text copies have separate hashes. Exact fake auth, shared credential forms and all `sk-*` patterns are removed from exports. Binary databases/compressed files remain private; a binary is never advertised as sanitized. Native exports are limited to 64 MiB per file, 256 MiB total, depth32 and 10000 entries; limits are recorded rather than silently omitted.

The HOME exporter skips symlinks, hardlinks and non-regular files. On Linux, held directory descriptors and `O_NOFOLLOW` protect traversal against agent-created links and path swaps. Failed startup/export retains evidence and fails the adapter. Unknown native tool-failure metrics are `null` with provenance, never manufactured zeros. Byte capture completeness does not assert that a native schema exposes every internal event.

Pi uses its pinned native `--mode json`; DSH uses native `--json` and durable HOME sessions. Neither baseline receives a planning patch. Our headless launcher subscribes to the existing event bus and writes `ERNIE_EVENT_JSON ` lines with schema `ernie-harness.event.v1` to stderr, preserving model messages and request settings.
