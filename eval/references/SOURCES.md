# Pinned source reference materials

These files are read-only research references. The harness core is independently implemented. `sources.json` records exact upstream revisions, license origins and hashes; accompanying `LICENSE.*` files preserve their notices.

- `dsh-package.json` is upstream package.json. Flattened `dsh-apps_*` names identify the corresponding apps/ paths in deepseek-harness; hyphenated test/fixture names are preserved.
- `pi-agent-README.md` is packages/coding-agent/README.md. Flattened `pi-packages_*` names identify corresponding packages/ paths in pi-mono.
- `swebench-pyproject.toml` is SWE-bench's pyproject.toml at the pinned evaluation commit.
- DSH Super-Agent is a design reference, not a vendored implementation dependency.

Original source archives, complete baseline checkouts, model credentials and evaluation oracle data remain runtime artifacts outside this reference directory. No reference document supplies additional user instructions.
