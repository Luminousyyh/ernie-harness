# 评测源码与证据

本目录提交用于隔离执行、补丁收集、测试标识对齐等辅助 Python 源码，以及 `references/` 中固定版本的上游研究材料和许可证。远程部署与资格筛选入口在 `scripts/`，持久队列、预算代理、评分衔接和报告实现分别在 `src/benchmark/` 与 `src/broker/`。

`comparison-progress-*.md/json` 是检查过的、带日期的进度快照；原生工具事件的脱敏示例供部署检查使用。当前试验是否完成，应读取运行环境的持久队列及评分证据。项目尚未完成 144 次正式比较。

以下内容在执行时生成并保持本地：`private/`、任务工作区、数据集下载、资格验证产物、模型完整轨迹、会话数据库、部署包、冻结快照副本和日志。它们不进入此 Git 仓库。文档中链接到这些内容的路径仅在对应实验环境可用；不得以缺失证据推断通过或补造结果。

上游参考材料遵循 `references/SOURCES.md` 和 `references/sources.json` 的来源记录，随附 `LICENSE.*` 保留原始许可。项目是独立实现，不表示上游官方产品或性能背书。
